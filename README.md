# 艾拉 Next · 1.0

作者：**桔梗**。本项目由桔梗一人创作。

艾拉是面向 Windows 的陪伴型桌面助手：桌宠常驻桌面，管理后台提供文字聊天、模型配置、长期记忆、语音、任务和应用接入。

**1.0 是当前工程的首个公开源码版本。** 游戏适配器、语音和任务模块已有实现，真实游戏连续游玩、麦克风与扬声器体验仍需分别验证。完整状态见 [功能状态](docs/功能状态.md)。

## 主要功能

- **桌宠与后台**：透明窗口、拖动、右键菜单、喂食、提醒、安静时段和数据备份。
- **聊天与记忆**：多会话文字聊天、可编辑的事实与偏好、来源追溯、可选向量召回、Token 用量记录。
- **模型与语音**：可配置本地或远程兼容服务；整句语音识别、流式生成、分句合成、连续监听与可选开口打断。
- **任务与应用**：展示具体计划、确认执行、核验结果和故障恢复；接入浏览器、Office 文件生成、Windows Office 及编程工作区。
- **游戏伙伴**：Minecraft Fabric、星露谷 SMAPI 与骑砍 GABS 接入源码；游戏资源与本体另行准备。

## 从源码启动

准备 Windows x64、Python 3.12、Node.js 24、项目指定的 pnpm、Rust MSVC 工具链、C++ Build Tools 和 WebView2。完整安装说明见 [快速开始](docs/快速开始.md)。在项目根目录执行：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e "services/runtime[dev,browser,office,office-live,screen]"
pnpm install --frozen-lockfile
pnpm tauri:dev
```

桌面端自动启动本地服务。右键桌宠或按 `Ctrl+Alt+E` 打开后台，在“模型路由”配置服务，再到“聊天测试”试聊。语音需要另行配置 ASR 与 TTS。

公开源码默认使用项目原创的 SVG 桌宠。可选 Live2D 模型与 Cubism Core 不随源码提供，获取与使用条件见 [第三方组件与素材](THIRD_PARTY_NOTICES.md)。不准备游戏资源也能启动桌面与聊天功能。

## 数据与许可

聊天、记忆和配置默认保存在本机 `%LOCALAPPDATA%\EllaNext`；API 密钥保存在 Windows 凭据库。使用远程模型、识别或合成服务时，相应内容会发送到所配置的服务。运行时仅监听本机回环地址，桌面 HTTP 与语音连接使用每次启动生成的会话令牌。
