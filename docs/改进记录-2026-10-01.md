## 运行与使用

运行 Tauri 会自动启动服务，不需额外打开 Python 终端。后台总览可看状态与日志。“应用接入”选择浏览器并开启联网回答后，可以在聊天或语音中说“查一下……”或提供公开网址。浏览器使用独立资料目录，登录和验证码需在该浏览器里处理。网页读取与搜索不代替任务中填写、点击的确认流程。

`scripts/package-desktop.ps1` 生成完整 Windows 安装 EXE，包含浏览器控制依赖；模型密钥与个人数据不进入安装包。MSI 的 WiX 链接步骤在本机失败，最终采用 [Tauri 支持的 NSIS 安装方式](https://v2.tauri.app/distribute/windows-installer/)。浏览器控制依据 [Playwright 官方 API](https://playwright.dev/python/docs/api/class-browsertype)，备用检索使用 [DuckDuckGo 的非 JavaScript 搜索](https://duckduckgo.com/duckduckgo-help-pages/features/non-javascript)。
