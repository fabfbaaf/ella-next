# 功能状态 · 1.0

1.0 固定当前工程作为首个公开源码版本，目标平台为 Windows x64。此页说明已有实现与验证范围；历史文档中的本机安装状态和旧安装包记录不代表公开源码附带这些资源。

## 已有实现

| 模块 | 1.0 范围 | 使用条件与边界 |
| --- | --- | --- |
| 桌面与后台 | 透明桌宠、拖动、菜单、双窗口、快捷键、运行时托管和服务状态 | 默认原创 SVG；可选 Live2D 资源自行准备；快捷键冲突时可用菜单 |
| 模型网关 | 主聊天/操作/视觉/人格路由，兼容服务配置，模型列表与生成检查，Token 用量 | 使用服务实际支持的模型 ID；列表成功不等于生成或图片能力可用 |
| 人格与文字聊天 | 统一人格、多会话、归档/恢复/删除、聊天来源引用与任务状态卡片 | 人格模型为可选第二层润色；普通兼容服务不保证工具规划可靠 |
| 长期记忆 | 事实/偏好/事件、来源、修正、删除、导出、对话摘要、文本与可选向量召回 | 删除记忆不自动删除原始聊天；向量服务不可用时回到文本检索 |
| 语音 | 整句识别、流式模型回复、分句 TTS、连续监听、暂停、可选开口打断、文字聊天接续 | 实际麦克风、回声与延迟需设备实测；文字与语音历史仍各自保存 |
| 任务 | 具体计划、按风险确认、实际核验、状态持久化、修订与重启恢复 | 执行结果未知时先核对现场；模型口头表示完成不能替代核验 |
| 浏览器与联网 | 独立浏览器资料目录、搜索、打开、读取、控件观察、确认后的填写/点击 | 需 Edge/Chrome 与 browser 依赖；登录、验证码、网站限制仍可能阻碍任务 |
| Office | 生成 Word/Excel/PPT；读取或修改活动 Excel、替换活动 Word 文字 | 文件生成与真实应用编辑有不同依赖；真实 Office 窗口尚待实测 |
| 编程工作区 | 文件列表、读取、指定替换、受限检查命令与只读 Git 查看 | 修改和检查命令先展示计划；修改限定在所选工作区 |
| 陪伴与提醒 | 饱腹/喂食、单次提醒、安静时段、任务和游戏进度、可选语音通知 | 重复提醒与系统级通知尚未接入；完整播放后才记为已播报 |
| 备份恢复 | 九个 SQLite 数据库的逐库快照、校验预览、确认后重启恢复 | 不含密钥、浏览器登录、录音、游戏/存档及工作文件；不是整机迁移 |

任务计划与确认绑定具体工具和参数。网页、文件修改和其他需确认的动作在执行前展示；批准失效或计划修订后需重新核对。桌面文件写入使用实际桌面目录并保留文件名；不会覆盖已有文件。

## 游戏适配器

公开源码包含自有游戏插件与运行时适配器。官方加载器、第三方模组、GABS 程序及完整部署 bundle 不随源码提供。准备方法见 [开发与构建](开发与构建.md)。以下版本是项目资源清单的支持范围，不表示其他版本已验证兼容。

| 游戏 | 当前接入范围 | 已实现的主要动作 | 待完成验收 |
| --- | --- | --- | --- |
| Minecraft Java | 26.2、Java 25、Fabric Loader 0.19.5+；官方启动器配置发现 | 移动、转向、视角、跳跃、快捷栏、所瞄准方块破坏、使用物品、单次攻击、等待 | 真实世界连续任务；制作、更完整背包/战斗/寻路与第三方启动器 |
| 星露谷物语 | Windows 1.6.14 至 1.7.0 之前、SMAPI 4.5+ | 移动、面向、工具、交互、槽位、普通对话、问答选择、箱子取放、普通货币购买、可安全退出的菜单 | 真实存档连续耕作、采集、交互与物品变化核验 |
| 骑马与砍杀 II | Native 1.3.15、GABS 与固定版本依赖 | 通过 GABS 读取状态、执行受控动作并核验；部分高影响动作提供精确预览与单次许可 | 真实战役与战斗连续任务、具体目标与数量的精确核验 |

三款游戏均需进入真实存档，状态持续更新后才开始目标循环。插件部署就绪、游戏成功启动或一次动作调用成功，都不能证明已完成连续游玩验收。动作未核验、状态丢失或重复动作没有进展时会暂停；重启后恢复为暂停，不自动重放动作。

骑砍普通自主游玩不包含宣战、读写存档、重开、永久角色修改、作弊或通用未知命令。允许预览的高影响操作仍绑定当前存档、精确动作与参数；缺少结构化存档 ID 或精确效果时不能授权。

屏幕陪聊为按需截图问答，需要前台游戏窗口和支持图片的模型；该模式只观察与聊天。连续实时视觉流尚未实现。

## 验证边界与后续工作

自动化验证覆盖隔离数据下的运行时、模拟模型/语音接口、任务恢复、浏览器并发、记忆、备份与游戏桥接规则。模拟接口不会证明实际提供方或硬件已可用；历史安装器也未必包含最后一次源码修改。公开版本的复现命令见 [开发与构建](开发与构建.md)。

以下项目仍需完成：

- 原生增量 ASR、正在播放半句的逐字时间对齐、本地音色包导入。
- 真实麦克风/扬声器与远程 TTS、Office/浏览器窗口和三款游戏存档的实机验收。
- 5060 / R7 780M 的延迟、显存、资源占用与多模型并发实测。
- 动态工具重规划、Minecraft 制作与更完整游戏操作闭环。
- macOS / Linux 桌面运行及安装流程；当前文档与打包以 Windows 为目标。
