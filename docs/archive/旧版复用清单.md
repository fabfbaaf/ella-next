# 旧版复用清单

> 历史记录：保留当时的开发状态与验证结果。当前使用说明见 [文档目录](../README.md)。

旧工程位于本目录上一级。复用以迁移接口、数据结构和经过验证的组件为主；不整包复制旧运行时。

| 新模块 | 旧版参考位置 | 迁移要点 |
| --- | --- | --- |
| 模型与人格 | `services/runtime/src/isla_runtime/modules/model_router/`、人格相关配置 | 复用模型路由、使用量结构、人格测试方法；重新统一聊天和操作输出的人格层 |
| 长期记忆 | `services/runtime/src/isla_runtime/modules/memory/` | 复用存储与检索思路，补齐来源、纠错、删除传播和导出验收 |
| 语音 | `services/runtime/src/isla_runtime/modules/voice/` | 复用提供方接口和音频链路，补齐打断/恢复场景 |
| 任务 Agent | `services/runtime/src/isla_runtime/modules/agent/`、`permissions/`、`tools/` | 复用工具权限与任务状态设计，统一中断恢复与动作验证 |
| Office/浏览器 | `services/runtime/src/isla_runtime/extensions/applications/` | 逐项迁移真实可用的适配器，并以实际文件/页面结果验收 |
| 游戏框架 | `services/runtime/src/isla_runtime/modules/game/` | 复用游戏发现、桥接和活动模式，重建统一控制闭环 |
| 我的世界 | `game/games/minecraft/` | Fabric 桥接已有观察/陪聊；旧版 `apply_action` 明确禁止控制，需新增可验证动作 |
| 星露谷 | `game/games/stardew_valley/` | SMAPI 桥接已有观察/陪聊；旧版 `apply_action` 明确禁止控制，需新增可验证动作 |
| 骑砍 | `game/games/bannerlord/` | GABS 控制接口可作为起点，需在真实游戏中验证持续游玩 |
| 桌宠/后台 | `apps/desktop/`、`packages/ui/` | 沿用双窗口和 2D 表现方式，逐步迁移可复用组件 |

迁移每一项时记录来源、适配修改和实测结果。旧版代码的存在不等于新项目功能已完成。
